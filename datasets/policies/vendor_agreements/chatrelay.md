# Data processing agreement: Northbridge Group and ChatRelay

_Synthetic agreement for the demonstration estate. Not a legal document._

Controller: Northbridge Group. Processor: ChatRelay (DE). Systems covered: Helpdesk and chat widget.

## 1. Subject matter

The Processor provides: Message translation.

## 2. Personal data

- the messages you send us

## 3. Instructions

The Processor processes personal data only on documented instructions from the Controller and keeps it confidential.

## 4. Security

The Processor applies appropriate technical and organisational measures and notifies the Controller of a personal data breach without undue delay.

## 5. Sub-processors

The Processor uses sub-processors only with the Controller's prior written authorisation.

## 6. International transfers

Processing takes place in a country covered by an adequacy decision.

## 7. Deletion

On termination the Processor deletes or returns all personal data.
